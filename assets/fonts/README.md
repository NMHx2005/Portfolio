# Fonts

`Inter-{latin,vietnamese}-{400,600}.woff` are the Inter typeface by The Inter Project Authors,
used only to render the generated Open Graph images (`src/lib/og.tsx`).

- Source: the `@fontsource/inter` package (`files/inter-{latin,vietnamese}-{400,600}-normal.woff`), which redistributes https://github.com/rsms/inter
- License: SIL Open Font License 1.1, full text in `LICENSE.txt` (copied from `rsms/inter` `LICENSE.txt`)
